Install

  1. Open MacHub.dmg.
  2. Drag MacHub into your Applications folder.
  3. Open MacHub from Applications or Launchpad.

If macOS says MacHub can’t be opened

MacHub is signed with an Apple Developer ID and notarized by Apple, so macOS only asks you to confirm the first launch by clicking Open. If macOS still blocks it, do either of these once:

  • Right-click (or Control-click) MacHub in Applications, choose Open, then Open again.
  • Or open System Settings › Privacy & Security, scroll to the message about MacHub and click Open Anyway.

Only download MacHub from machub.space.

Optional tools

MacHub works on its own. Some tools use command-line programs you install separately:

  • Device Logs: adb (Android platform-tools), flutter, idevicesyslog (libimobiledevice) and Xcode’s xcrun
  • AAB to APK: bundletool (brew install bundletool), plus Java if you use a bundletool.jar, and adb for installing
  • Git Clone and Project Analyzer: git
  • Package Analyzer: apksigner from the Android SDK build-tools is optional

Permissions you may be asked for

  • Screen Recording: Screenshot OCR captures a region you select
  • Automation: opening Terminal for commands and a Finder fallback for protected files
  • Full Disk Access (optional): only if you bookmark files macOS protects

Uninstall

Quit MacHub and drag it to the Trash. To remove its saved data too, see How do I reset MacHub?
