The toolbox

Everything you reach for, one click away

Four groups in a single sidebar. Each tool keeps its state while you switch, so you never lose your place.

Files & Paths

Path Checker

Paste or drop a path and instantly see whether it is a file, a folder or missing. Reveal it in Finder, copy it, and revisit your last 50 checks.

File Utilities

Bookmark the files you edit often, like ~/.zshrc or /etc/hosts, and open them in any app or run a saved shell command on them.

Dir Utilities

Tag and filter your workspace folders, then open them in Finder, VS Code, Cursor, Android Studio, Xcode, IntelliJ, iTerm and more.

Text & Data

Payload Decoder

Auto-detects and unwraps layered payloads (JWT, JSON, URL encoding, hex, Gzip, Base64) up to eight layers deep, shown as a JSON tree.

Data Format

Pretty-print or minify JSON, XML, HTML, YAML, CSV, query strings, SQL and CSS, with find and a tree view.

Text Diff

Side-by-side diff with line and character-level highlights, next/previous navigation and search.

Base64 Image

Decode one or many base64 strings or data URIs into images you can preview, repair, copy or save in bulk.

Devices & Packages

Device Logs

Live adb logcat, flutter logs and iOS syslog (devices and simulators) with level, package and text filters.

Package Analyzer

Inspect any APK, AAB or IPA: versions, SDKs, permissions, signing, native libraries, provisioning and a size breakdown.

Project Analyzer

Scan a folder for languages, lines of code, largest files and detected stacks, with a git change summary.

AAB to APK

Convert an Android App Bundle into an installable universal APK with bundletool, then install it on a connected device.

Utilities

Screenshot OCR

Capture any region and read its text with Apple Vision, on your Mac. Optionally translate it into 15 languages.

Custom Commands

Save the shell commands you keep retyping and run them in the background or in Terminal.

Git Clone

Clone through the right SSH account alias and add web and upstream remotes in one go.

Android release workflow

From .aab to a running app, without leaving MacHub

Drop an Android App Bundle to inspect it, then turn it into a universal APK with bundletool. Sign with your debug keystore or your own, and install straight to a connected phone.

  • Package Analyzer reads APK, AAB and IPA: IDs, versions, SDKs, permissions, signing and size
  • Convert creates the APK; Convert & Install runs adb install -r too
  • Keystore passwords are never saved and are masked in the log

Privacy

Built to stay out of your way and out of your data

No account, no analytics, no ads. Here is exactly what the app does.

Stays on your Mac

Bookmarks, saved commands, last-used folders and the history of the text tools live in your Mac’s local preferences. Nothing is synced or uploaded.

Only when you ask

  • Translate sends the recognized text to Google Translate
  • The git “upstream” option asks the GitHub API for a fork’s parent
  • Settings › Changelog opens a web page

Honest about permissions

Screen Recording for OCR captures, Automation for Terminal and Finder helpers, and optional Full Disk Access for protected files. MacHub runs outside the App Sandbox so it can launch your tools.

FAQ

Quick answers

Is MacHub free?

Yes. MacHub is free to download and use.

Does MacHub collect my data?

No. There is no account, no analytics, no crash reporting and no ads. Your bookmarks, commands and history stay in your Mac’s local preferences. The few network requests the app can make only happen when you ask for them; see the Privacy Policy.

Which Macs does it run on?

macOS 12 Monterey or later, on Apple Silicon and Intel. Automatic language detection in Screenshot OCR for Chinese, Japanese and Korean needs macOS 13 or later.

Why isn’t it on the Mac App Store?

MacHub launches tools such as adb, git and bundletool and reads files you choose, so it runs outside the App Sandbox. That is why it is distributed as a DMG from this site.

Do I need the Android SDK, Flutter or git installed?

Only for the tools that use them. MacHub looks in the usual locations, shows an install hint when something is missing, and lets you point it at the right file with Set path….
